# Flutter Store Testing Study

Flutter product-store study with Dio, Provider and tests for product models, repositories and presentation state.

## Project scope

A study or technical-challenge implementation from its original development period. It is shared as a portfolio reference; the original implementation and commit history are preserved.

## Stack and SDK

- Flutter and Dart.
- Main declared packages: `google_fonts`, `dio`, `provider`.
- Dart SDK constraint from `pubspec.yaml`: `>=2.16.1 <3.0.0`.

Use a Flutter release with a Dart SDK inside that range. Dependency modernization is a separate change from publishing this historical example.

## Run

```bash
flutter pub get
flutter run
```

## Tests

The repository contains 6 Dart test files matching `*_test.dart`. Run the existing suite with a compatible SDK:

```bash
flutter test
```

Test files are learning artifacts; their presence is not a claim that they have passed on a current Flutter release.
